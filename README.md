
# 🛠 RemoPro

RemoPro — мобильное приложение для управления ремонтными проектами, поиска подрядчиков, создания заказов и общения между клиентами и исполнителями.

---

## 🚀 Стек технологий

- **React Native** (Expo CLI)
- **Zustand** — управление глобальным состоянием
- **Tailwind CSS (NativeWind)** — стилизация компонентов
- **React Navigation** — навигация между экранами
- **@testing-library/react-native** + **Jest** — тестирование компонентов и стора

---

## 📂 Структура проекта

```
RemoPro/
├── assets/                 # Изображения и иконки
├── components/             # Компоненты интерфейса (карточки, фильтры и т.д.)
├── jest/                   # Настройки и моки для тестирования
├── mock/                   # Моковые данные (если используются)
├── navigation/             # Навигация приложения (AppNavigator, табы клиента и подрядчика)
├── screens/                # Экраны приложения
│   ├── client/             # Экраны клиента (пользователя)
│   │   └── projectCreate/  # Подэкраны создания проекта
│   ├── common/             # Общие экраны (логин, регистрация)
│   └── contractor/         # Экраны подрядчика
├── store/                  # Zustand store и тесты для стора
├── utils/                  # Конфиги и утилиты
├── App.js                  # Точка входа в приложение
├── package.json            # Зависимости проекта
└── tailwind.config.js      # Конфигурация Tailwind для NativeWind
```

## ⚙️ Установка проекта

1. Клонируйте репозиторий:

```bash
git clone https://github.com/Bernando0/RemoPro.git
cd RemoPro
```

2. Установите зависимости:

```bash
npm install
```

3. Запустите Expo CLI:

```bash
npx expo start
```

или для мобильного устройства:

```bash
npm run android
# или
npm run ios
```

## 🧪 Тестирование

Проект покрыт базовыми тестами:

- Тестирование работы стора через **@testing-library/react-native**.
- Тестирование навигации по ролям пользователей.

Запустить тесты:

```bash
npm run test
```

Тесты находятся в папке `__tests__` внутри `store/` и `navigation/`.

## 📈 Особенности проекта

- Разделение навигации и пользовательских потоков по ролям: **клиент** и **подрядчик**.
- Упрощённое глобальное состояние через **Zustand** без лишнего усложнения Redux.
- Использование **TailwindCSS** для удобной и быстрой стилизации.
- Поддержка базового тестирования навигации и стора.
- Продуманная архитектура проекта, легко масштабируемая под новые фичи.
